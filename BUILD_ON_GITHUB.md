# Сборка APK через GitHub Actions

1. Создайте **private** репозиторий GitHub `Moydodyr`.
2. Загрузите **содержимое** папки `Moydodyr` в корень репозитория, сохраняя `.github/workflows/android.yml`.
3. Откройте вкладку **Actions** → **Build Android APK** → **Run workflow**.
4. После успешного запуска откройте результат сборки и скачайте артефакт `Moydodyr-debug-apk`.
5. APK находится внутри скачанного ZIP.

## ВАЖНО

Это **прототип**, не готовый детский блокировщик. Сборка не гарантирована без теста CI.
В assets отсутствуют и текст `verses.txt`, и файлы русской офлайн-модели `model-ru`.
Не реализованы: ввод и безопасное хранение родительского PIN, автоматическое завершение чтения, гарантированное перекрытие чужих приложений, защита от обхода и корректная проверка последовательности слов.
Не устанавливайте прототип как единственное средство родительского контроля.
PIN не должен храниться в исходном коде или GitHub.
