# Состояние сборки

Исходный код изменён: кнопка «Я закончил читать» удалена. После единственного нажатия «Начать чтение» Vosk слушает непрерывно, а после каждого завершённого речевого фрагмента проверяет накопленный текст. При достижении 80% слов в исходном порядке доступ открывается автоматически. При недостаточном совпадении микрофон продолжает слушать.

Сборка APK в текущем окружении не выполнена: отсутствуют Android SDK и Gradle. GitHub Actions workflow включён, но не запускался и не проверялся.

Ограничения: необходимо импортировать TXT с текстом стихотворения; Android ограничивает автоматический запуск служб и окон в фоне, поэтому блокировка не гарантирована в любой ситуации; PIN задаётся пользователем при первом запуске; приложение не заменяет системный экран блокировки.
